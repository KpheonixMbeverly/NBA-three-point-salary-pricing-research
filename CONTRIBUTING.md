# Contributing and Reporting Issues

Thank you for helping improve reproducibility. Open a GitHub issue for:

- a data-source discrepancy (include season, team, player, original source URL);
- a claim that the source CSV omits or duplicates a player-season observation;
- an incorrectly defined variable (include expected formula and the test case);
- evidence that franchise aliases or playoff rankings were mismatched; or
- a hypothesis-testing/identification weakness that merits a separate analysis.

Please do not upload copyrighted raw salary/statistical extracts, proprietary
scouting files or personal identifying information in an issue. Code changes
should include a test and describe whether they **replicate** the historical
poster or instead define a **revised model**. Do not silently relabel revised
estimates as original poster results.
